# Tweaks are declared as data, never run as scripts

A Tweak is declared as data (registry values, single bits of a binary registry value, boot settings, service start types, scheduled tasks) and executed by one shared engine; only a Tweak that cannot be expressed as data becomes a hand-written Coded Tweak in C#. PowerShell scripts are never used, because earlier attempts (AkariOS-Companion) mixed scripts with registry code, which made state impossible to read back, undo reliably, or test.

v1 ships without a Coded Tweak contract: every v1 Tweak can be declared as data, so the engine handles Declared Tweaks only. The contract is added together with the first Tweak that actually needs code, so its shape comes from a real case rather than a guess.

_Amended 2026-10-12 (#23): a single bit of a binary registry value, such as an effect in UserPreferencesMask, is also data. Reading or writing it touches only that bit, so it keeps Live State, Original Values and Undo exact without any code per Tweak._

_Amended 2026-10-12 (#26): a boot setting of the current Windows entry (bcdedit {current}) is data too, read and written with System32's bcdedit. A missing one means Windows' default, like a missing registry value._

_Amended 2026-10-12: a few registry keys belong to a Windows service, and Administrators may only read them; Settings changes them through the service. A value under such a key is still data. WindowsMachine writes it with the restore privilege every administrator has, as backup tools do, and only for keys on its explicit ServiceOwnedKeys list (so far Windows Search's SystemIndex, for Find my files). The key's permissions are never changed, and nothing runs as SYSTEM or TrustedInstaller._

_Amended 2026-10-13: this ADR binds **Tweaks**. An **Action** (see [0004](0004-akari-dash-covers-tweaks-and-actions.md)) may start a process — a package manager, an installer, DDU — because that is what installing software is, and there is no state to read back and undo. Actions still do not ship as PowerShell: the step that has to run in safe mode, where a WinUI app cannot, is a small console exe beside the app rather than a `.ps1` written to disk and launched through RunOnce with the execution policy bypassed._

_Amended 2026-10-16 (#26, Defender optimize): the no-SYSTEM/TrustedInstaller rule above now has exactly one carve-out. Windows does not let Defender's own keys be written from a normal boot at all, by anyone, tamper protection being what it is; safe boot plus TrustedInstaller is the only way, and it is what AkariOS-Ultimate does. So the safe-mode companion — the same console exe pattern as the Action above, run from RunOnce — points the TrustedInstaller service's own binary at itself, as AkariOS's `Run-Trusted` does, does the writing in that one process, and puts the binary path back. The carve-out is narrow by construction: the values are still declared as data in the catalog (`security.defender-optimize`), only the write is deferred; the app itself never runs elevated beyond the administrator manifest it already has, no elevation is permanent, and the service's binary path is restored whatever happens. Everything else still obeys the rule._

_Amended 2026-10-19 (#33, Drivers page): the Drivers page is the one place scripts run. It is AkariOS-Ultimate's Graphics category 1:1: each button runs that entry's own script block (`Scripts/Graphics/*.ps1`, embedded) after the helpers Akari.ps1 gives it. DDU is the exception inside the exception: its script only downloads and configures DDU, and the safe-mode run is a pass in the same queue, RunOnce entry and companion exe as Disable Defender, so the rule above about no `.ps1` through RunOnce still holds. The user's call: these scripts are proven on real cards in AkariOS-Ultimate, the 2026-10-15 C# rewrite of them was removed, and driver state (DDU, installers, profile imports, per-adapter keys) cannot be read back reliably anyway. They are Actions, so nothing on that page claims Live State, Original Values or Undo; "Revert" is the script's own. No Tweak anywhere else may become a script on the strength of this._
