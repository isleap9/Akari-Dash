# System management is out of scope for v1

v1 covers gaming performance plus debloat/privacy changes, all as reversible Tweaks; system-management items (Defender, BitLocker, update policy, installers, driver tools, stress tests) and live monitoring are excluded. Earlier Akari projects died partly from this scope creep; if these return later they become a separate concept, never Tweaks, since most have no readable state and no undo.

_Superseded 2026-10-13 by [0004](0004-akari-dash-covers-tweaks-and-actions.md). Update policy, installers and driver tools are in scope; they arrive as **Actions**, the separate concept this ADR said they would need. Live monitoring and stress tests stay out._
