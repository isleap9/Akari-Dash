# Tweak content is written fresh; Winhance is an index of ideas, never a source to copy

Winhance is licensed PolyForm Shield 1.0.0, which forbids using it in a competing product, and Akari-Dash is one. AkariOS-Companion and Akari-Tool are both based on Winhance. Tweaks are written from the Akari-OS / FR33THY scripts (MIT) and public Windows documentation.

Winhance (and the projects based on it) may be read to find out which Windows settings exist, but nothing is copied from it: every Tweak's registry values, services or tasks are confirmed against Microsoft's documentation, Akari-OS, or the setting's own behaviour in Windows, and its title, description, Options, Recommended Option and Group are Akari-Dash's own. The selection is Akari-Dash's too: it is never one of Winhance's lists taken whole.
